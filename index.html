La solution

Un framework qui structure tes sessions

INTemple transforme chaque chat en systeme modulaire avec des roles specialises et une memoire organisee.

#DAISY

Generateur creatif

Brainstorming divergent. 8+ variantes, analogies cross-domaines, anti-patterns eclairants.

#DAYZ

Analyseur structurel

Decomposition hierarchique. Composants, relations, invariants, anomalies.

#KEYZ

Triageur / Scoring

Priorisation multi-critere. Urgence, impact, effort, risque. Scores de 0 a 1.

#E3

Expanseur 3 axes

Horizontal (analogies), Vertical (abstraction), Radial (connexions inattendues).

#TEMPLE

Validateur

Coherence, contradictions, completude. Verdict : VALIDE / PARTIEL / INVALIDE.

#NDIM

Encodeur multi-axe

Projection sur 5 dimensions qualitatives : temporel, conceptuel, relationnel, transcendant, contra-forme.

#MEM

Memoire 3 niveaux

Ecume (volatile), Creux (session), Ocean (permanent). Anti-perte de contexte.

#HOP

Orchestrateur

Route automatiquement vers le bon module. Planifie les pipelines.

Questions

FAQ

Ca marche avec quel LLM ?
Tous. Les prompts sont du texte brut en Markdown. Claude, GPT-4, Gemini, Mistral, Ollama, LM Studio, n'importe quel chat qui accepte un system prompt ou un message texte.
C'est quoi la difference avec un simple prompt ?
Un prompt est une instruction isolee. INTemple est un systeme complet : modules specialises, memoire structuree, pipelines sequentiels, commandes de controle. C'est la difference entre taper une commande dans le terminal et utiliser un OS.
Je dois etre technique pour l'utiliser ?
Non. C'est du copy-paste. Tu colles le system prompt, puis tu utilises les balises (#DAISY, #PIPE create, etc.) dans tes messages. Si tu sais ecrire dans un chat, tu sais utiliser INTemple.
Combien de fichiers je recois ?
24 fichiers Markdown + 1 export JSON. Organises par categorie : system prompts, modules, pipelines, sessions, cheatsheet. Plus un JSON structure pour integration programmatique.
Y a-t-il des mises a jour ?
Oui. L'achat inclut toutes les mises a jour futures. Nouveaux modules, nouveaux pipelines, optimisations basees sur les retours utilisateurs.
