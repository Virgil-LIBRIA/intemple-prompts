# INTemple Prompts

Architecture cognitive structuree pour LLM — pack de prompts conversationnels copy-pastables dans n'importe quel modele.

## Demo

[Voir la landing page](https://virgil-libria.github.io/intemple-prompts/)

## Contenu

8 modules cognitifs, 7 pipelines de travail, 5 sessions guidees.
Chaque prompt est un fichier Markdown autonome, utilisable tel quel dans ChatGPT, Claude, Gemini ou tout autre LLM.
